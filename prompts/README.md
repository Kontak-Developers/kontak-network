# Ajan promptları (Nida)

Ajan beyninin kullandığı promptlar burada durur. Workflow bunları dosyadan okur, kod değiştirmeden düzenlenebilir.

- `analiz.md`: taranan TikTok/Instagram gönderilerinden günlük gündem raporu çıkarır (yükselen konular, sesler, formatlar)
- `uretim.md`: gündem + marka profilinden 3 içerik fikri üretir (kanca, senaryo, açıklama, hashtag, görsel promptu)

Çıktı formatı her zaman JSON, şeması `PLAN.md` içindeki `/api/trends` ve `/api/ideas` ile aynı.
